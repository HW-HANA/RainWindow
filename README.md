# 听窗 · RainWindow

独立实现的雨窗交互原型。无需依赖安装、构建或网络服务。

## 打开

Windows 推荐双击 start.cmd：自动启动本地服务并打开网页（需要已安装 Node.js）。关闭或重启电脑后，再次双击即可。也可直接双击 index.html，或在此目录运行 `node server.cjs`，访问 `http://127.0.0.1:4173`。需要 WebGL 2；声音在点击“开启声音”后播放。

## 交互

- 汽车：夜城背景、汽车窗框、雨声和雨滴敲击声。
- 列车：用户提供的横向城市夜景背景、金属窗框、轻微摇晃、缓慢风景位移、雨声、低频运行声和成对轨道接缝声。
- 雾气独立于外侧雨滴：鼠标按住或手指滑动擦雾，约几十秒逐渐恢复。外侧雨滴不会擦掉内侧雾气。
- 指尖留水滴：按行进距离随机生成少量内侧水珠，可关闭；开关控制后续生成，已有水珠自然下滑、消失。
- 可调整雨势、雾浓、指宽、窗大小和音量；可关闭列车运动、沉浸显示、重置雾面、上传自己的风景照片。照片不上传任何服务器。
- 系统设置减少动态效果时默认关闭列车晃动。页面隐藏时停止绘制并暂停音频。

## 实现与边界

`app.js` 独立生成球冠法线贴图，Canvas 更新水滴位置、粘滞、合并和残留，再交由 WebGL 2 片元着色器进行背景偏移折射。雾面使用独立可擦除遮罩，带采样散射、冷色混合和细微噪声。指尖水滴单独绘制在内侧。窗框、窗台、失焦车厢前景共同构成层次。

列车默认背景为用户提供的 city.jpg，逆时针旋转 90° 后保存于 assets/train-city.jpg；保留原始宽高比，通过居中裁切适配窗户。汽车背景仍为程序绘制，声音使用 Web Audio 合成，并非实地录音。列车背景位移属于小幅视差，不是无限连续行驶场景。雨滴为视觉近似模拟，不是完整流体仿真。


文件：`index.html` 页面结构；`style.css` 视觉与响应式；`app.js` 图形/交互/声音；`server.cjs` 可选本地服务器。

音频：assets/train-ambience.mp3 为列车声，assets/rain-ambience.mp3 为雨声。点击开启声音后按场景播放，文件音量已分别限制在约 24% 和 32% 以内。
